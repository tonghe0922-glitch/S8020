# 组织架构详情页面复刻说明

本次在现有真实组织架构闭环上重构展示层，不新增平行数据源。

## 技术端

- 左侧组织目录支持搜索、类型/状态筛选、展开与收起。
- 右侧详情工作台包含基本信息、真实直属成员、负责人、编制使用率和权限中心入口。
- 组织新增、修改、级联启停、软删除继续调用现有正式 API。

## 员工端

- 使用全宽层级组织图展示当前已发布组织架构。
- 点击组织卡片打开详情抽屉，展示职责、负责人、编制、直属成员和下级组织。
- 数据继续来自 `/api/v1/org/directory`，员工端保持只读。

## 管理端

- 复用全宽组织图和详情抽屉版式。
- 保留创建草稿、保存、提交审批、通过/驳回、发布和废弃的完整闭环。
- 草稿发布前不会影响技术端和员工端正式组织数据。

## 质量验证

- 组织架构页面继续使用真实组织、通讯录、草稿与授权接口。
- 组织编码明确标注为“系统自动生成”，保持只读并禁止前端提交修改。
- 严格类型检查、ESLint 和全部前端单元测试通过后，才允许进入完整 CI 与主分支合并。
- 临时修复工作流已清理，仓库最终仅保留正式 `ci.yml`。
